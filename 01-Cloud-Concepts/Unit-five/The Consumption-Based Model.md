# 💰 Module: The Consumption-Based Model

Cloud computing changes how organizations pay for and manage IT resources.

---

## 💸 Financial Concepts: CapEx vs. OpEx

| Concept | Definition | Example in IT |
| :--- | :--- | :--- |
| **CapEx** (Capital Expenditure) | Up-front spending on physical infrastructure. | Buying physical servers, storage, and networking hardware. |
| **OpEx** (Operational Expenditure) | Ongoing spending on services or products as you use them. | Paying a monthly Azure bill (Pay-as-you-go). |

> **Note:** Cloud computing is classified as an **OpEx** because you pay as you consume.

---

## 📈 Benefits of Consumption-Based Model

1.  **No Upfront Costs:** No need to spend millions before starting your project.
2.  **No Wasted Capacity:** You don't pay for "idle" servers that aren't doing anything.
3.  **Perfect Scaling:**
    - **Scale Out:** Add resources when demand is high (e.g., Black Friday).
    - **Scale In:** Remove resources when demand drops to save money.

---

## 🏗️ Capacity Planning: Traditional vs. Cloud

- **Traditional:** You must predict the future. Overestimating leads to wasted money; underestimating leads to bad performance.
- **Cloud:** You match resources to **Actual Demand**. You are agile and can react to changes in seconds.

---

## 💡 Key Takeaway
The cloud provider handles the "dirty work" (Power, cooling, hardware maintenance), so you can focus on **solving business problems** and delivering value to your users.
