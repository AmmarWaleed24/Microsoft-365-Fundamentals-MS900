# ☁️ Module 01: Describe Cloud Concepts

This section covers the fundamental principles of cloud computing, service models, and the shared responsibility model.

---

## 🎯 Learning Objectives
- Define Cloud Computing.
- Compare Public, Private, and Hybrid cloud models.
- Differentiate between IaaS, PaaS, and SaaS.
- Identify the benefits of cloud services (High Availability, Scalability, Agility).

---

## 🏗️ 1. Cloud Service Models (The "Who Does What"?)

| Model | Description | Responsibility |
| :--- | :--- | :--- |
| **IaaS** | Infrastructure as a Service (Servers, Storage). | You manage OS, Apps, and Data. |
| **PaaS** | Platform as a Service (Development tools). | You manage Apps and Data. |
| **SaaS** | Software as a Service (M365, Teams). | Microsoft manages everything. |

---

## 🌐 2. Cloud Deployment Models

1. **Public Cloud:** Resources are owned and operated by a third-party cloud service provider (Microsoft).
2. **Private Cloud:** Resources are used exclusively by a single organization (On-premises).
3. **Hybrid Cloud:** Combines public and private clouds, allowing data and applications to be shared between them.

---

## 🚀 3. Key Benefits of Cloud

- **Scalability:** The ability to increase or decrease resources based on demand (**Vertical vs Horizontal**).
- **High Availability:** Ensuring the system remains accessible even if a hardware failure occurs.
- **Fault Tolerance:** The ability of a system to continue operating despite failures.
- **Agility:** The speed at which you can develop, test, and launch software applications.

---

## 💰 4. Expenditure Models
- **CapEx (Capital Expenditure):** Upfront spending on physical infrastructure (Servers, Data Centers).
- **OpEx (Operational Expenditure):** Spending on services and products as you use them (The Cloud model).
